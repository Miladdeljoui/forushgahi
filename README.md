# فروشگاه پارس | PARS Store

پروژه اولیه اپلیکیشن اندروید فروشگاه لوازم مرغداری پارس، با رابط فارسی و راست‌چین.

## امکانات نسخه اولیه
- رابط سفید و فارسی (RTL)
- فهرست محصولات کاتالوگ رسمی پارس به‌همراه محصولات قیمت‌دار Digitoyour (در مجموع ۱۰۳ قلم)
- سبد خرید و محاسبه جمع اقلام دارای قیمت تأییدشده
- نمایش «تماس بگیرید» برای محصولاتی که قیمت آن‌ها مشخص نیست
- فرم ثبت اطلاعات مشتری و آدرس
- آماده‌سازی متن سفارش و باز کردن پیامک به شماره فروشگاه: **09122375820**

## وضعیت مهم
این نسخه، اسکلت اولیه پروژه است و هنوز APK آماده انتشار نیست.
- فهرست فعلی ۱۰۳ قلم دارد: ۹۱ محصول از منبع قیمت‌دار Digitoyour و ۱۲ قلم اضافی از کاتالوگ رسمی parshafez.ir. قیمت‌های عددی از Digitoyour کپی شده‌اند و اتصال زنده برای به‌روزرسانی قیمت وجود ندارد. قیمت‌های فاقد تطبیق دقیق عمداً «تماس بگیرید» نشان داده می‌شوند. قیمت‌های پیش‌فرض تکراری سایت رسمی به‌عنوان قیمت واقعی استفاده نشده‌اند.
- ارسال خودکار سفارش، ذخیره سفارش روی سرور و درگاه پرداخت واقعی به بک‌اند نیاز دارد.
- هزینه ارسال فعلاً تعیین نشده و نباید به‌عنوان مبلغ قطعی نمایش داده شود.
